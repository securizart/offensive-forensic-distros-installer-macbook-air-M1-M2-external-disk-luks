# iK4lN3 — Digital Forensic Environment

*For M1 / M2 Apple Silicon · "The truth leaves a trace"*

**iK4lN3** is the optional digital-forensic personality this installer can
build on top of an Ubuntu 24.04 (Asahi) system on Apple Silicon. It pairs
a curated open-source forensic toolset with a MATE desktop arranged for
forensic work.

## About the name

*iK4lN3* (read **"i-KAINE"**) is an homage to **CAINE — Computer Aided
INvestigative Environment**, the Italian GNU/Linux live forensic
distribution created and maintained by Giovanni "Nanni" Bassetti, which
inspired this work.

The name is deliberately its own. **iK4lN3 is not CAINE**, is **not
affiliated with, sponsored by, or endorsed by** the CAINE project, and
does **not** redistribute CAINE's ISO, packages, name, logo, wallpaper,
icons, Caja scripts, or any other CAINE-branded material.

## Why a re-implementation instead of "CAINE on ARM"

CAINE is distributed as a modified **live ISO for x86-64**, not as a
software repository — there is nothing to "convert" to `arm64` or to
re-badge, and its image can't simply be run on Apple Silicon. So iK4lN3
does not repackage CAINE; it **independently reconstructs** a comparable
environment for `arm64` from upstream sources:

- **Tools.** The forensic tools are the same upstream, open-source
  packages that CAINE and other forensic distros build on — The Sleuth
  Kit, Autopsy, plaso, the libyal utilities, Volatility, Guymager,
  ddrescue, and so on — installed directly from the **Ubuntu / Debian**
  archives (mostly `universe`, plus a small set built from source in an
  isolated virtualenv). Each tool keeps its own license and copyright and
  belongs to its respective authors. Only the subset that has a real
  `arm64` build is installed; see `forensics/caine/packages-skip.txt` for
  what is intentionally left out and why.
- **Look & feel.** The "Forensic Tools" menu — organised into
  CAINE-style categories (Analysis, Disks, Hash, Memory Forensics,
  Registry, Timeline, Network Forensics, Malware, Password Recovery) — the
  classic MATE panel, and the launchers are **generated by this project's
  own scripts** (`forensics/caine/12_install_caine_desktop.sh`), using
  standard freedesktop/MATE mechanisms and **system-theme icons**. No
  CAINE menu files, themes, or icons are copied.
- **Branding.** The *iK4lN3* wordmark, the wallpaper
  (`iK4lN3_wallpaper_1k.png`), and the tagline *"The truth leaves a
  trace"* are original to this project.

In short: **the same open-source tools and the same spirit, but an
independent implementation and independent branding.**

## What is *not* included

CAINE's signature integrated pieces that are CAINE's own work — its
write-blocking/mounter behaviour, its Caja preview scripts, its reporting
front-end, its artwork — are **not** taken from CAINE. Any equivalent
capability in iK4lN3 is implemented independently and documented as such.
