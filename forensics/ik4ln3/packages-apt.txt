# packages-apt.txt
# iK4lN3 forensic toolset — subset that installs natively on Ubuntu 24.04
# LTS (noble) for arm64, straight from the Ubuntu archive (mostly
# 'universe'; a few in 'main'). Cross-checked against noble's binary-arm64
# Packages indexes: every entry here is arch 'any'/'all'/'linux-any', i.e.
# a real arm64 build exists. One package per line; '#' comments and blank
# lines are ignored by 10_install_ik4ln3_apt.sh.
#
# Deliberately EXCLUDED from this file (handled elsewhere or dropped):
#   - GRUB / kernel / bootloader packages  -> never touched here, see
#     the big note in steps/09_package_installation.sh (ik4ln3 branch).
#   - x86-only tools (aeskeyfind, cmospwd, rar, syslinux*)  -> packages-skip.txt
#   - renamed-in-noble packages            -> packages-renamed.txt
#   - pip/source-only tools                -> packages-pip.txt
