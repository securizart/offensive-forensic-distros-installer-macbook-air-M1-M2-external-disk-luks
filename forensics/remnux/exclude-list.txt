# exclude-list.txt
#
# WARNING: this file is NO LONGER used as the exclude= argument to
# `state.apply` — doing so breaks Salt's high-state compilation (see
# remnux/FINDINGS.md, section "Why exclude= was abandoned as an
# install mechanism", for the real error and the explanation). It's
# kept as reference documentation of the known failure points in a
# full remnux.addon run. The actual cleanup of broken binaries is
# done by remnux/cleanup.sh after a run with no exclusions.
#
# List of remnux/salt-states .sls files categorized during the
# investigation of the ~120 failures from the full run on arm64.
# Format: one sls path per line (dotted path). Lines starting with # are ignored.
# Category in brackets at the end of each comment:
#   [LOUD]     Salt marks Failed; amd64 .deb with unresolvable apt dependencies.
#   [SILENT]   Salt marks Succeeded, but the installed binary throws "Exec format error".
#   [PIP-TAG]  pip explicitly rejects the wheel ("not a supported wheel on this platform").
#   [BUILD]    Fails compiling/packaging from source; may not be arm64-specific.
#   [NO-PKG]   The package simply doesn't exist in Ubuntu's repos for this version/arch.
#   [SALT-MOD] The Salt state module isn't available in this Salt version (3008.2).
#   [CASCADE]  Fails because it depends on something else in this same list.
